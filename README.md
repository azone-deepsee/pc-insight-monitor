# PC Insight Monitor

**α版 v1.0** — USB / COM トラブル調査用のリアルタイム監視ツール

現場PCでバラバラに確認していた USB・COM・Windowsイベントログ・QRツールの接続ログを、**1本のタイムライン** にまとめて表示します。

---

## 特徴

- **サーバ不要** — Webサーバや exe は使いません
- **Python インストール不要** — ポータブル Python を同梱してファイルサーバから実行
- **QRツール改修不要** — 既存の USB 接続 CSV ログを取り込んで統合表示
- **調査時に手動起動** — 常時バックグラウンド監視は将来対応（α版は調査用）

---

## 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 / 11（64bit） |
| 権限 | 一般ユーザー（管理者不要な場合が多い） |
| ネットワーク | ファイルサーバからフォルダ実行可能であること |
| その他 | PowerShell 実行可 |

## クイックスタート

### 現場PC（調査時）

1. ファイルサーバ上の `pc_insight_monitor` フォルダを開く
2. **`run.bat`** をダブルクリック
3. **「監視開始」** をクリック
4. 現象を再現し、**「タイムライン」** タブで変化を確認
5. 終了時にウィンドウを閉じる

### 開発PC（初回セットアップ）

配布用フォルダを作る前に、開発PCで **1回だけ** 以下を実行します。

```bat
setup_portable.bat
```

これにより `python\` フォルダに Python 埋め込み版と依存パッケージが入ります。  
完了後、フォルダ一式をファイルサーバへ配置してください。

## QRツールのログ連携

QRツールが出力している USB 接続/遮断 CSV を、調査時にタイムラインへ統合できます。

### 設定方法

`config.json` を編集します。

```json
{
  "qr_log": {
    "enabled": true,
    "directory": "D:\\Logs\\QR",
    "pattern": "*.csv"
  }
}
```

| キー | 説明 |
|------|------|
| `directory` | QRツールのログフォルダパス |
| `pattern` | 取り込むファイル（既定: `*.csv`） |

### 取込手順

1. `config.json` にログフォルダを設定
2. アプリを起動
3. **「QRログ取込」** をクリック

接続・遮断を示すキーワード（接続、遮断、connect、disconnect など）を含む行を自動判別します。  
CSV形式が特殊な場合は [Issue](https://github.com/azone-deepsee/pc-insight-monitor/issues) で共有いただければパーサを調整します。

## ログの保存場所

調査セッションのログは各PCのローカルに保存されます（ファイルサーバには書き込みません）。

```text
%LOCALAPPDATA%\PCInsightMonitor\logs\session_YYYYMMDD_HHMMSS.csv
```

エクスプローラーで `%LOCALAPPDATA%\PCInsightMonitor\logs` と入力して開けます。

## 調査の進め方（推奨）

1. トラブル再現 **前** に「監視開始」
2. いつも通り操作して現象を再現
3. タイムラインで次の順序を確認
   - QRログの接続/遮断
   - Kernel-PnP などのイベント
   - COM の Status 変化（OK → Unknown など）
4. 必要なら QRログを取り込んで時系列を補完
5. 終了後、ローカルの CSV ログを保管

## トラブルシューティング

### 起動しない

- `python\python.exe` があるか確認 → なければ開発PCで `setup_portable.bat` を再実行
- ファイルサーバのパスに日本語や特殊文字が多い場合、ローカルにコピーして試す

### USB名が文字化けする

- α v1.0 では cp932 対応済み。再発する場合は OS 言語設定とあわせて Issue を報告してください

### イベントログが表示されない

- `pywin32` が正しくセットアップされているか確認（`setup_portable.bat` を再実行）
- 起動**後**に発生したイベントのみ表示されます（過去ログは対象外）

### QRログが取り込めない

- `config.json` の `directory` パスが正しいか確認
- CSV に日時列があるか確認（`YYYY-MM-DD HH:MM:SS` 形式など）
